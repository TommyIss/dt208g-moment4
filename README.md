# Moment 4 i kursen DT208G, Programmering i TypeScript

## Moment 4
Min applikation hämtar data om kurser från en JSON-fil genom HttpClient i form av en array av den förskapad interface som definierar datastruktur. Applikation hanterar data och visar kurser för användare i tabell-form(Kurskod, Kursnamn, Progression), man kan hitta kursplan genom att klicka på respektive kurskod för att öppna kursplanen i en annan flik.
Det finns ett inmatningsfält där man kan filterera kurser genom att mata in kurskod eller kursnamn. Man kan klicka på kurskod eller kursnamn, och sortera kurser enligt kursnamn eller kurskod i stigande eller fallande ordning.
